FUNDAMENTOS

¿Qué es una ecuación?

Una ecuación es una igualdad matemática que contiene uno o más valores desconocidos llamados incógnitas. Resolverla consiste en encontrar los valores que hacen verdadera esa igualdad.

Los elementos de una ecuación

3x + 5 = 20
  • Incógnita: x, el valor que buscamos.
  • Coeficiente: 3, el número que multiplica a x.
  • Constantes: 5 y 20, números conocidos.
  • Signo de igualdad: =, indica que ambos lados tienen el mismo valor.

Ejemplo 1: ecuación sencilla

x + 5 = 12
  1. Restamos 5 a ambos lados.
  2. x = 12 − 5
  3. x = 7
Comprobación: 7 + 5 = 12 ✓

Ejemplo 2: multiplicación

3x = 18
  1. Dividimos ambos lados entre 3.
  2. x = 18 ÷ 3
  3. x = 6
Comprobación: 3 × 6 = 18 ✓

Ejemplo 3: dos operaciones

2x + 4 = 14
  1. Restamos 4: 2x = 10.
  2. Dividimos entre 2.
  3. x = 5
Comprobación: 2(5) + 4 = 14 ✓
Regla importante: lo que hacemos en un lado de la igualdad también debemos hacerlo en el otro para conservarla. Las operaciones inversas ayudan a despejar la incógnita.
NUEVO DESAFÍOS

Ecuaciones de segundo grado

Son ecuaciones en las que la incógnita aparece elevada al cuadrado. Su forma general es ax² + bx + c = 0, donde a es diferente de cero.

x²

Forma general

ax² + bx + c = 0

a, b y c son coeficientes conocidos; x es la incógnita. Estas ecuaciones pueden tener dos soluciones reales, una solución real doble o ninguna solución real.

Ejemplo: x² − 9 = 0

  1. Sumamos 9 a ambos lados: x² = 9.
  2. Calculamos la raíz cuadrada.
  3. x = 3 o x = −3.
Ambas soluciones funcionan: 3² − 9 = 0 y (−3)² − 9 = 0.

Fórmula general

x = (−b ± √(b² − 4ac)) / 2a

Permite calcular las soluciones de cualquier ecuación de segundo grado. El discriminante b² − 4ac ayuda a determinar cuántas soluciones reales existen.

DOS INCÓGNITAS

Sistemas de ecuaciones

Un sistema es un conjunto de dos o más ecuaciones que comparten incógnitas. Su solución debe cumplir todas las ecuaciones simultáneamente.

Observa el sistema

x + y = 10
x − y = 2

Buscamos dos números cuya suma sea 10 y cuya diferencia sea 2.

Resolución paso a paso

  1. Sumamos las ecuaciones: 2x = 12.
  2. Despejamos: x = 6.
  3. Sustituimos en x + y = 10.
  4. 6 + y = 10.
  5. y = 4.
Solución: (6, 4)

Comprobación

6 + 4 = 10 ✓
6 − 4 = 2 ✓

La pareja (6, 4) cumple las dos ecuaciones. Por eso es la solución del sistema.

Aplicación cotidiana: si dos cuadernos y un lápiz cuestan cierta cantidad, y otra combinación tiene un precio diferente, podemos construir un sistema para descubrir el precio de cada producto.
ESTRATEGIAS

Métodos para resolver sistemas

Hay diferentes procedimientos para encontrar las incógnitas. Podemos elegir el que resulte más sencillo según las ecuaciones.

➕

1. Método de reducción

Se suman o restan las ecuaciones para eliminar una incógnita. Después se despeja la variable restante.

x + y = 8
x − y = 2
  1. Sumamos: 2x = 10.
  2. x = 5.
  3. Sustituimos: 5 + y = 8.
  4. y = 3.
🔄

2. Método de sustitución

Despejamos una variable en una ecuación y sustituimos su expresión en la otra.

y = 6 − x
2x + y = 9
  1. Sustituimos: 2x + 6 − x = 9.
  2. x + 6 = 9.
  3. x = 3.
  4. y = 3.
⚖️

3. Método de igualación

Despejamos la misma incógnita en ambas ecuaciones e igualamos las expresiones obtenidas.

y = 2x
y = x + 3
  1. Igualamos: 2x = x + 3.
  2. x = 3.
  3. Sustituimos: y = 2(3).
  4. y = 6.
📈

4. Método gráfico

Representamos cada ecuación como una recta en el plano cartesiano. La intersección indica la solución cuando existe un único punto de cruce.

y = x + 1
y = −x + 5

Igualando las expresiones obtenemos x = 2 y, por tanto, y = 3. Las rectas se cruzan en (2, 3).

INTERPRETACIÓN

Tipos de soluciones de un sistema

Según la relación entre las ecuaciones, un sistema puede tener una solución, infinitas soluciones o ninguna.

Tipo Características Resultado
Sistema compatible determinado Las rectas se cruzan en un solo punto. Una solución.
Sistema compatible indeterminado Las ecuaciones representan la misma recta. Infinitas soluciones.
Sistema incompatible Las rectas son paralelas y diferentes. Ninguna solución.
